# gGame Map Overlay

対象ウインドウからマップ名と座標を読み取り、壁・モンスター境界・出入口などをゲーム画面に重ねて表示する Windows アプリです。

## はじめかた

1. `gGameMapOverlay.exe` を起動します。  
   初回は OCR モデルをダウンロードするか確認されるので、「はい」を選びます。  
   「いいえ」を選ぶと、精度が少し低い Windows 標準 OCR を使います。
2. オーバーレイを表示させるウインドウを選択します。
3. ゲームを前面にすると読み取りが始まり、ゲーム画面にマスが重なって表示されます。

読み取るのはゲームが前面にあるときだけです。ほかのウィンドウを操作している間は止まり、オーバーレイも隠れます。

## メイン画面

- 読み取ったマップ名と座標が表示されます。
- チェックボックスで、表示するマスの種類を切り替えます。
- **一時停止** で読み取りを止めます。

## オーバーレイ

| 初期の色 | 内容 |
|---|---|
| 赤 | 壁。岩や海など、通れないマスの外周 |
| 青 | モンスター境界 |
| 緑 | 出入口。別のマップへ移動するマス |
| 紫 | その他の特殊なマス |
| 黄色の枠 | キャラクターのいるマス |

- オーバーレイはクリックを通すので、表示したままゲームを操作できます。
- 座標を読み取ってから描くため、移動中は少し遅れて追いかけます。
- ウィンドウの大きさを変えても、マスの大きさは自動で合わせます。

## 設定画面

変更はその場で反映され、自動で保存されます。

- **OCR**: マップ名の言語と OCR エンジンを選びます。日本語・韓国語・英語に対応しています。
- **オーバーレイの表示**: マスの種類ごとに色と不透明度を変えられます。
- **オーバーレイの移動**: キャラクターが歩いたときのマスの動かし方を選びます。
- **全般**: タスクトレイに常駐させると、閉じてもトレイに残ります。
  トレイのアイコンをダブルクリックすると画面が戻り、右クリックの **終了** で終了します。

## 設定ファイルとモデル

- 設定は実行ファイルと同じフォルダーの `config.json` に保存されます。フォルダーごとコピーすれば設定も一緒に移せます。
- Program Files など、書き込みできないフォルダーには置かないでください。
- OCR モデルは `models` フォルダーに保存されます。ネットワークの制限でダウンロードできない場合は、別の環境で取得したファイルをここに置いてください。

## 自動更新

起動時にアプリ本体とマップ情報の新しい版を確認し、見つかれば更新するか確認します。
設定画面の **更新を確認…** からも確認できます。
更新に失敗した場合は、元の状態に戻ります。
